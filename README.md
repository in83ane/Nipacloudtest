# Helpdesk Support - Staff Control Panel

A production-grade staff portal for centralized ticket management, customer directory tracking, and real-time operational analytics.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Supabase (PostgreSQL)
- Chart.js / Recharts

## Key Features
- **Kanban Board:** Full-width drag-and-drop board for seamless state management.
- **Command Center:** Real-time metrics, resolution rates, and workload distribution charts.
- **Customer Directory:** Track user activity logs with one-click access to specific ticket details.
- **Audit Trails:** Zero-delete policy enforced via immutable `change_logs`.

## Setup Guide

1. Clone the repository and configure your environment variables (refer to `.env.example`).
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
